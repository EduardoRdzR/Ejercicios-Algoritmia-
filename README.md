# Algoritmos de Optimización: Ejercicios 1 al 5

Cada ejercicio es un programa independiente. `tsp_utils.py` contiene las funciones compartidas
de TSP (distancias, 2-opt, MST, Held-Karp y recocido simulado) y debe estar en la misma carpeta.

    pip install -r requirements.txt
    python ejercicio1.py
    python ejercicio2.py
    python ejercicio3.py
    python ejercicio4.py
    python ejercicio5.py

Cada programa imprime sus resultados en consola y guarda las gráficas en la carpeta `resultados/`.
